## Что изменено в этой итерации
- **Вход**: атомарный OTP (Lua в Redis: один успех при гонке, пятая неверная попытка сжигает код); публичное имя/slug не из e-mail (`User` + `user-<8 символов>`); Google и Facebook (серверный code-flow, state + cookie `bl_oauth_flow`, PKCE для Google, онбординг через `bl_onboarding`, привязка/отвязка, защита `last_identity`, аккаунты по e-mail не сливаются); публичный `GET /slugs/check`; миграция `0013`.
- **Последний администратор**: общий `pg_advisory_xact_lock(7007)` в revoke, bootstrap, удалении и очистке аккаунта.
- **Доступ и кэш**: `private, no-store` на изменяемом контенте, профилях, Ideas, поиске, комментариях, `/resources`, sitemap-entries, `/i18n/meta`; кэш только у словарей и категорий. Страницы Next.js динамические, без ISR. Go принимает `/api/v1/*` только от Caddy (`TRUSTED_PROXY_CIDRS`) с `X-Proxy-Secret` (исключение — публичные GET словарей и категорий). Комментарии, ответы, постоянные ссылки и жалобы проверяют текущую видимость цели.
- **Контент**: `PutIfAbsent` для файлов ревизий, CAS по ETag для `manifest.json`, живой индекс = ровно `published_rev`, переводчик без `--force` (код 2), запись только `PutIfAbsent`, блоки кода (``` и ~~~) и таблицы не режутся; Content Sync сверяет sha256 известных файлов, отклоняет подмену и более старый manifest, повторяет неудавшуюся статью.
- **Мессенджер**: перепроверка блокировок под замком, `actor_id` в событии `conversation`; запрос принимает ровно 3 сообщения при гонке; идемпотентный повтор.
- **Приватность и эксплуатация**: удаление аккаунта чистит согласия и IP в аудите; `CleanupReports` (90/180 дней) и `CleanupAudit` (90 дней); согласованный бэкап PostgreSQL + S3 с заморозкой записи и `restore-test.sh`.
- **Устойчивость**: consumer outbox пересоздаёт группу после потери данных Redis (нашлось при прогоне Playwright); SSE-клиент переподключается по событию `online`.
- **Витрина** `apps/org` (beeloy.org) и Worker `beeloy-org`; CI-задача `org` с проверкой canonical и отсутствия cookie.
- **Доступность**: контраст жёлтой темы (палитра `brand`, подчёркнутые ссылки).

## Отклонения от ТЗ (осознанные)
1. `audit.Service.List` не проверяет права сам (избежание циклического импорта `acl`↔`audit`): право `audit.view` проверяет обработчик `/admin/audit`.
2. Словарь-запас на фронтенде — полный `contracts/messages/en.json` (копия `fallback-en.json`), а не подмножество; словарь API накладывается поверх.
3. Защита страниц (`RequireAuth`, роли) — на клиенте (UX); все права проверяет API. Ограниченные (`restricted`) статьи загружаются браузером, чтобы публичный кэш не содержал закрытого.
4. При окончательном удалении аккаунта комментарии стираются (тело очищается, статус `deleted`), а не только обезличиваются.
5. Для локальной разработки вместо MinIO (публичные образы больше недоступны) используется `adobe/s3mock`.
6. `GET /readyz` и `/healthz` лежат вне `/api/v1`; для контейнера добавлена подкоманда `/api healthcheck` (в distroless нет curl).
7. Локали: 26 = 24 языка ЕС + русский + украинский (в ранней версии ТЗ список был неверным; исправлено).
8. Режим `proxy.ts` (Node) на Cloudflare у OpenNext помечен как экспериментальный; локально работает (см. спайк). План отката описан в `SPIKE-T05.md`.
