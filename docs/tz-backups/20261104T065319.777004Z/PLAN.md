# План реализации Beeloy (на основе ТЗ, 58 задач)

Статус: план составлен, **реализация не начата**. Сроки не назначены: ТЗ не содержит данных о размере команды и бюджете, поэтому объём указан в относительных единицах (S ≈ до полудня работы исполнителя-модели, M ≈ день, L ≈ 2–3 дня, XL ≈ неделя). Единицы — ориентир для очередности, а не обещание.

Исполняет задачи автоматический исполнитель (слабая модель) по `09-tasks.md`; человек подключается в точках, отмеченных 👤.

## 1. Принципы

1. **Вертикальные срезы раньше ширины.** Сначала один рабочий путь «браузер → Cloudflare → Go → PostgreSQL» (веха M1), затем наращивание функций.
2. **Риск раньше объёма.** Самое неопределённое — совместимость Next.js с Cloudflare Workers и проксирование `/api/*` на `api-site.beeloy.com`, включая SSE (T05) — проверяется первым.
3. **Каждая веха заканчивается проверяемым состоянием** (команда, тест, демонстрация) и коммитом-тегом `m<N>`.
4. **Слабой модели — малые шаги.** Не больше одной задачи за сессию; после задачи — полный прогон тестов пакета; вопросы пишутся в `docs/tz/QUESTIONS.md`.
5. **Внешние действия (деплой, DNS, секреты, аккаунты) выполняет человек** или исполнитель только после явного разрешения.

## 5. Риски и меры

| Риск | Вероятность | Мера |
|---|---|---|
| Next.js не работает на Cloudflare Workers как ожидалось | средняя | спайк T05 до любых UI-задач; запасной вариант — прямые запросы на `api-site`; крайний — Node-хостинг frontend (решение заказчика) |
| Слабая модель отклоняется от ТЗ | высокая | малые задачи, критерии приёмки, `QUESTIONS.md`, ревью человеком после каждой вехи |
| Расхождение Go-API и TypeScript-типов | средняя | T55, контракт-тесты, правило «экран после тестов эндпоинтов» |
| Качество/скорость машинного перевода на Ollama | средняя | CLI по одной статье, валидация (URL, код, плейсхолдеры), человек проверяет словарь перед релизом |
| Потеря сообщений/событий | низкая | outbox + Streams, интеграционные тесты, алерты по лагу |
| Ошибки прав доступа (утечка черновиков, диалогов) | средняя, высокий ущерб | T56: 14 негативных сценариев; ACL-таблица ≥ 40 строк |
| Единственный сервер Hetzner | высокая | внешние бэкапы, ежемесячный `restore-test`, заранее описанный RPO 24 ч / RTO 4 ч |
| Юридическая неготовность | высокая | `TODO-LEGAL` явно блокирует запуск (ворота M8) |
| SEO: машинные переводы 25 языков | средняя | пометка `origin=machine`, решение 👤10 до запуска |
