## Существенные риски

| Риск | Последствие | Предлагаемая мера |
|---|---|---|
| Недоступная история решений | Противоречие исходному замыслу | Сверка с полным экспортом |
| Неограниченный MVP | Рост сроков и сложности | Согласовать обязательные сценарии |
| Несовместимость Next.js/edge | Переработка frontend | Ранний прототип на целевой платформе |
| Ошибки ACL | Утечка объектов и диалогов | Серверные проверки и негативные тесты |
| Неверное объединение identity | Захват аккаунта | Проверяемая привязка провайдера |
| Частичное обновление 26 словарей | Смешение версий | Валидация и атомарная публикация |
| Redis как единственная история | Потеря сообщений/состояния | Постоянное хранение в PostgreSQL |
| Единственный узел Hetzner | Простой и потеря данных | Внешние бэкапы, восстановление, RPO/RTO |
| Неопределённая приватность | Неверные UX и операции с данными | Политика обработки до запуска |
| UGC, спам, жалобы | Нагрузка на модерацию | Лимиты, блокировки и процесс рассмотрения |
| Дубли языка/домена/slug | SEO-фрагментация | Согласованная схема URL и canonical |

## Открытые вопросы с приоритетом

**До фиксации спецификации:** получить полный текст исходной беседы; подтвердить философию, аудиторию, продуктовые сценарии, бизнес-модель и границы .org/.com; утвердить список 26 языков и MVP; согласовать роли и модель контента.

**До реализации соответствующей области:** выбрать канал OTP, политику account linking и сессий; схему slug; механику Ideas; объём мессенджера и шифрование; runtime Content Sync Worker, источник истины и формат JSON; маршрут API, Cloudflare runtime и версии; SQL driver и миграции.

**До публичного запуска:** определить оператора, сроки обработки и удаления данных, cookies/аналитику, юридические документы; проверить восстановление бэкапов, наблюдаемость, аварийный откат, доступность интерфейса, SEO и модерацию.

## Предлагаемая последовательность

1. Восстановление и сверка исходных решений, подтверждение MVP.
2. Проверочный вертикальный сценарий: frontend на Cloudflare → Go на Hetzner → PostgreSQL, плюс локализация из проверенной версии JSON.
3. Identity, ACL и публичные адреса.
4. Согласованные публичные и редакционные сценарии, Ideas.
5. Мессенджер с проверкой изоляции и восстановления соединения.
6. Юридическая, эксплуатационная и продуктовая готовность к запуску.

Последовательность — предложение без согласованных сроков и обязательств. Документация не фиксирует реализацию этих этапов.
