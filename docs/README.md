## Как читать

- **Задано** — прямо указано в текущем запросе; используется как исходное требование.
- **Предложение** — рабочая детализация для обсуждения, а не восстановленное решение из прошлого чата.
- **Открыто** — данных недостаточно; решение не принято в этой документации.

Упоминание технологии не означает, что она уже установлена или развёрнута. Изменений приложения и инфраструктуры при подготовке документации не выполнялось.
